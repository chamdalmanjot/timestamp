Timestamp Microservice

Saturday, October 3, 2026

Send a date or a unix time to the API and get both formats back as JSON.

How to use

  • By date: /api/2026-10-03
  • By unix time: /api/1790985600000
  • Current time: /api/

What you get back

{"unix":1790985600000, "utc":"Sat, 03 Oct 2026 00:00:00 GMT"}
